## Getting started

### 1. Clone the repository

```bash
git clone https://github.com/tabish-showkat/pytorch-learning-for-ml-.git
cd pytorch-learning-for-ml-
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate   # Linux/macOS
# or
venv\Scripts\activate      # Windows
```

### 3. Install PyTorch

For CPU support:

```bash
pip install torch torchvision torchaudio
```

If you want a specific PyTorch version or GPU support, you may install according to your system and CUDA version from the official PyTorch website.

### 4. Install Jupyter

```bash
pip install notebook jupyter
```

### 5. Run notebooks

```bash
jupyter notebook
```

Then open the notebook files in the browser and start learning.
